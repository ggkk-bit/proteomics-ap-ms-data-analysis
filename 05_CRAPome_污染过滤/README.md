# CRAPome 污染过滤

CRAPome 是 AP-MS 数据的污染过滤层，不承担主打分算法。目标是把 MaxQuant 或同类 AP-MS 结果整理成 CRAPome 可接受的上传格式，并基于污染频率、对照背景和富集结果做筛选与可视化。

## 核心原理

CRAPome 本质上是背景污染过滤层，核心问题是：
- 这个 prey 是真实互作，还是高频背景蛋白
- 它在对照里出现得有多频繁

所以它最依赖对照样本标记，而不是单一评分值。

## 目录结构

- `1.原始输入`：原始 `proteinGroups.txt`
- `2.样本信息与分组`：样本注释、对照信息
- `3.数据清洗与预处理`：基础清洗
- `4.CRAPome输入文件`：CRAPome 上传格式
- `5.质控`：输入检查
- `6.CRAPome过滤结果`：过滤结果
- `7.可视化`：图表
- `8.文档与参考`：参考材料
- `脚本`：脚本文件

## 执行流程

### 完整流程

1. 将原始 `proteinGroups.txt`、样本注释、对照信息放入 `1.原始输入` 和 `2.样本信息与分组`
2. 先做基础清洗，删除 `Reverse/反向匹配`、`Potential contaminant/潜在污染物`、`Only identified by site/仅位点鉴定蛋白`
3. 将清洗后的结果转换成 CRAPome 需要的长表上传格式
4. 用 CRAPome 的污染频率和富集结果筛选候选互作蛋白
5. 输出通用图形，检查不同 bait、不同重复和对照之间的一致性

## 输入要求

### CRAPome 上传格式

CRAPome 上传分析的核心输入是四列长表：
- `Bait Name`
- `AP Name`
- `Prey Name`
- `Spectral Count`

### 样本约定

- 对照样本建议统一写成 `CONTROL`
- 同一 bait 的不同生物重复，建议在 `AP Name` 中用稳定编号区分，例如 `R1`、`R2`、`R3`
- 如果只拥有 `proteinGroups.txt`，它只能作为蛋白实体和基础过滤来源，不能单独恢复 CRAPome 所需的样本级谱数表；通常还需要 `evidence.txt`、样本级谱数矩阵，或其他能还原每个 AP 的计数信息的上游结果

## 筛选原则

- **第一层**：只做 MaxQuant 常规污染过滤，不在这里过早引入强阈值
- **第二层**：看 CRAPome 污染频率，优先保留在本项目 bait 中富集、但在公开对照库中低频出现的蛋白
- **第三层**：结合重复一致性、谱数和已知背景蛋白列表做最终人工审阅

## 输出说明

### 推荐输出

- 背景频率统计
- 过滤后结果
- 被剔除污染物
- 每个 bait 的过滤摘要

## 注意事项

CRAPome 与其它算法并列，输入重点是对照样本、背景频率、过滤前后对比。
