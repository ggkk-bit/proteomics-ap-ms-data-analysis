# 公共准备：从 proteinGroups.txt 出发

这个目录不是某一个算法专用，而是给 `CompPASS`、`MiST`、`HGSCore`、`CS Score`、`CRAPome`、`PPIrank` 共用的起点。

当前先做两件事：

1. 检查 `proteinGroups.txt` 里有哪些样本列可用
2. 生成一份可人工补全的样本注释模板
3. 把宽表按样本展开成统一的长表

## 建议流程

1. 先运行 `脚本/01_检查proteinGroups样本列.R`
2. 查看 `输出/样本列清单.tsv`
3. 再运行 `脚本/02_生成样本注释模板.R`
4. 人工补全 `输出/样本注释模板.tsv` 中的 bait、重复、是否保留等信息
5. 运行 `脚本/03_根据样本注释展开样本级长表.R`
6. 后续各算法目录都引用这份样本注释表和样本级长表

## 为什么先做这个

- `MiST` 依赖 bait 和重复定义
- `CompPASS` 依赖 bait-prey 在不同实验中的分布
- `CRAPome` 依赖对照样本标记
- `PPIrank` 依赖 bait、重复、对照和后续边表构建
- `HGSCore` / `CS Score` 也都离不开统一的样本命名

所以这里先把“样本是谁、属于哪一组、是不是对照”这件事定死。

## 输出文件

- `输出/样本列清单.tsv`
- `输出/样本注释模板.tsv`
- `输出/样本级长表.tsv`
- `输出/运行说明.txt`

## 当前约定

- 源文件优先使用上一级测试目录中的 `proteinGroups.txt`
- 定量列优先识别：
  - `Intensity `
  - `LFQ intensity `
  - `iBAQ `
- 真正进入各算法前，还会再按算法需要分别清洗
