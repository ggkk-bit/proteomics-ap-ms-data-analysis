# CompPASS 结果筛选说明

## 1. 总体原则

CompPASS 的核心思想不是给出一个跨所有数据集通用的固定阈值，而是根据 prey 在整个 AP-MS 数据集中的背景频率、丰度和重复支持，给出相对排序。因此，CompPASS 更适合：

- 先排序
- 再按 bait 分层筛选
- 最后结合重复、污染过滤和生物学信息解释

## 2. 优先看的分数

### 2.1 `scoreWD`

建议作为主排序指标。WD 分数在原始 D-score 基础上进一步考虑重复支持和权重，常作为高置信候选筛选的首要依据。

### 2.2 `scoreZ`

建议作为辅助 enrichment 指标。`scoreZ` 高，说明 prey 在该 bait 下相对背景更突出。

### 2.3 `AvePSM` 或平均丰度

可用于排除纯粹由极低计数支撑的边缘候选。

## 3. 实用筛选建议

### 3.1 第一层：基础保留

建议先保留：

- `scoreWD > 0`
- `countPrey` 或 `AvePSM` 不是极低噪音值
- prey 未被已知污染库高度怀疑

原因：负值或接近零的 WD 往往缺乏足够的特异性支持。

### 3.2 第二层：按 bait 排序

对每个 bait：

- 优先保留 `scoreWD` 排名前 5% 到 10% 的 prey
- 或先保留前 10 到 20 个 prey 作为高置信候选

原因：CompPASS 更强调相对排序，不同 bait 的分数分布可能不完全一致。

### 3.3 第三层：结合 Z 分数

如果结果表中有 `scoreZ`，建议补充条件：

- `scoreZ >= 2` 作为较稳妥的 enrichment 参考线
- `scoreZ >= 1` 可作为宽松探索线

这里不是绝对阈值，而是接近原始 CompPASS 使用习惯的经验筛选方式。

### 3.4 第四层：重复支持

如果有重复，建议额外要求：

- 同一 bait 下 prey 至少在 2 个 run 中出现
- 或在单个 run 中极高丰度，但需要人工复核

## 4. 建议分层

### 高置信

- `scoreWD` 位于各 bait 前列
- `scoreZ` 较高
- 有重复支持
- 不属于常见背景污染

### 中置信

- `scoreWD` 尚可
- `scoreZ` 中等
- 重复支持有限，但生物学上合理

### 低置信/待排除

- `scoreWD` 接近 0
- `scoreZ` 低
- 仅单次弱信号出现
- 属于常见背景蛋白

## 5. 为什么不建议只用一个固定阈值

原因有三点：

1. 不同数据集的 bait 组成和背景复杂度不同
2. 不同 prey 的整体出现频率不同
3. CompPASS 本身更强调大规模数据集中的相对排序

因此更推荐“按 bait 排序 + WD 主导 + Z 辅助 + 重复/污染校正”的组合筛选方式。

## 6. 参考方法习惯

本说明参考的是以下类型的方法习惯：

- 原始 CompPASS 文献中对 Z-score、D-score/WD-score 的使用逻辑
- 后续 AP-MS 大规模互作研究中基于 WD/NWD 识别高置信互作的做法
- 与 MiST、SAINT 等方法并行使用时常见的分层筛选框架

在真正形成结论时，建议再叠加 CRAPome 或其他背景污染过滤信息。
