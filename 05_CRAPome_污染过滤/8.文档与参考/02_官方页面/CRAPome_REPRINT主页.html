Introduction

The Resource for Evaluation of Protein Interaction Networks (REPRINT) is collection of computational tools for the analysis of affinity purification mass spectrometry data. It comprises of (a) the current version of the contaminant repository for affinity purification mass spectrometry data (CRAPome V2.0) and (b) an integrated pipeline to analyze user generated APMS data. The pipeline is an extension of the CRAPome “user data analysis” workflow with several new features including i) additional scoring functions, ii) tools to visualize scored interactions and iii) an advanced network generation and analysis tool.
