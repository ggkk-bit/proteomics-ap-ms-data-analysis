# MiST 结果筛选说明

## 默认筛选原则

- 先按 `MiST score` 过滤
- 再看重复支持
- 再看是否像背景蛋白
- 最后再结合生物学常识人工复核

## 推荐阈值

- 高置信起点：`MiST >= 0.75`
- 候选区间：`0.68 <= MiST < 0.75`
- 低置信：`MiST < 0.68`

## 为什么这样筛

- MiST 论文给出的经典推荐阈值就是 `0.75`
- 如果 feature weights 是固定权重，阈值不应低于最高 feature weight
- 低于阈值的边通常更像背景或单次偶发命中

## 二次筛选建议

- 优先保留在多个重复里都能稳定出现的互作
- 优先保留 specificity 高、background 低的互作
- 如果某条边 abundance 很高但 reproducibility 很差，通常要降级
- 如果某条边 reproducibility 很好但 specificity 很差，通常是背景蛋白

## 可选控制文件的用途

- `remove.txt`：强制移除明显不想保留的样本或条目
- `collapse.txt`：把同类 bait 合并到一个组里
- `specificity_exclusions.txt`：排除某些 bait 组之间的特异性惩罚

## 与文献和常用做法的对应

- 依据：MiST 官方 protocol 和后续 AP-MS 使用习惯
- 常见做法：先用 `0.75` 做高置信，再结合 ROC / PR 和已知正例微调
