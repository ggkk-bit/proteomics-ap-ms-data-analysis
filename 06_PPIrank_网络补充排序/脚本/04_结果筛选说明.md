# PPIrank 结果筛选说明

## 必须先做的硬过滤

- 删除 `Reverse`
- 删除 `Potential contaminant`
- 删除 `Only identified by site`
- 删除缺失 bait / prey / spectral count 的记录

这些是 MaxQuant / AP-MS 结果里最基础的去噪步骤，不属于 PPIrank 特有规则，但属于前置必需条件。

## PPIrank 结果筛选建议

1. 先保留满足以下条件的互作：
   - 至少有 `3` 个生物学重复支持
   - 存在负对照
   - 在三个重复里都只有 `1 SC` 的互作优先剔除

2. 再按统计结果筛：
   - `PPIRank score` 越高越靠前
   - `p-value` / `FDR` 先做保守截断
   - 没有金标准时，先取前 `5% ~ 10%` 做人工复核，再结合已知互作集调整

3. 结果展示可再做一层“可视化专用筛选”：
   - 去除热休克蛋白、核糖体蛋白等典型高频背景
   - 但这一步建议只用于出图，不建议作为主统计阈值

## 为什么这样筛

- 论文明确指出：单个谱图计数且重复性弱的互作容易是噪声。
- 负对照能帮助估计背景分布，减少假阳性。
- `PPIrank` 强调的是“排序”，所以最好用金标准或已知互作集合校准截断点，而不是只凭单一经验阈值。

- `PPIrank` 原文
- 同类 TAP/MS 方法对 `spectral count`、`negative control`、`replicate` 的通用习惯
- 与 `BioGRID` 等已知互作库的重叠评估
